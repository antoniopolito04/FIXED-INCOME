# Fixed Income Portfolio Risk Analytics

A zero-coupon curve bootstrap and multi-methodology risk framework for a US Treasury
barbell portfolio — built end to end from raw market quotes to a fully reconciled VaR
framework, on a single self-consistent curve.

**Full write-up:** [`TECHNICAL_REPORT.pdf`](TECHNICAL_REPORT.pdf) (19 pages — methodology,
results, cross-validation, known limitations, and a market-context read dated September 2026)

## What this is

One bootstrapped Treasury curve feeds one consistent pricing function, from which every
downstream risk metric — duration, convexity, DV01, Key Rate Duration, VaR/ES — is derived
by **full re-pricing**, never by a separate closed-form shortcut. That "one curve, one pricer,
many risk lenses" design is the central methodological choice of the project, and it's what
lets every metric be cross-checked against every other (see Section 5 of the report).

The portfolio under analysis is a $1,000,000 notional barbell (T-Bill 6M / T-Note 2Y /
T-Bond 20Y), priced off 12 on-the-run US Treasury securities.

**Highlights:**
- Zero-coupon curve bootstrap (bills + coupon bonds, Act/365 curve axis, Act/Act ICMA accrual)
- Full-reprice effective duration, convexity, DV01, and non-parallel scenario stress testing
- Implied forward curve, carry & roll-down
- Key Rate Duration via tent-weight node decomposition
- Three-methodology VaR/ES: Gaussian parametric, Monte Carlo full revaluation, and
  Cornish-Fisher (analytical Delta-Gamma)
- Factor volatilities calibrated on ~420 days of real Treasury CMT history (not placeholder
  assumptions) — see `src/calibrate_factor_vols.py` and report §4.3.1

## Quickstart

```bash
pip install -r requirements.txt

cd src/
python bootstrap_yield_curve.py           # curve nodes -> console + CSV
python portfolio_risk_stress_test.py      # pricing, risk, stress -> console + CSV + 2 dashboards
python calibrate_factor_vols.py           # optional: refresh factor vol calibration -> console
python advanced_risk_analytics.py         # forward/carry, KRD, VaR, Cornish-Fisher -> console + CSV + dashboard
```

Each script is self-contained when run standalone; Modules 2 and 3 import their inputs
directly from Module 1 (and Module 3 additionally from Module 2), so there is exactly one
bootstrapped curve and one pricing function feeding every number in the report.
`calibrate_factor_vols.py` is not wired into the automatic pipeline by design — it prints its
recommended constants rather than writing them, so a re-calibration is always a deliberate,
reviewed step.
